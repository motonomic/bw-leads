Enquiry Report Builder

Upload the Enquiry Detailed Report from HMSI. You get one Excel file with the open enquiries for each sales executive and the invoiced customers, each with follow-up counts and dates.

Reports

Drop report files here Excel (.xlsx, .xls) or CSV. Add more than one report, such as October and November, and they are merged by enquiry number.

Files are read in this browser tab and are not uploaded anywhere. If an enquiry appears in two reports, the one from the later “data as of” date is used.

What the Excel file contains

Sheets

  • Summary: open enquiries, average follow-ups, no follow-up, overdue and invoiced for each executive
  • Model Wise: enquiries for each model by stage, share, booked or invoiced %, and executive
  • Open, one sheet per executive: enquiries at Enquiry or Quotation stage, oldest first
  • Invoiced: invoiced customers in the same format

Columns

Enquiry Number · Enquiry Date · Customer Name · Mobile No. · Model · Enquiry Source · Classification · Current Status · Times Followed Up · Last Follow-up Date · Last Follow-up Remark · Next Follow-up Date · Flag · Data As Of

Summary

By model

Models are counted as named in the report, all stages included. Booked or invoiced % = (Booking + Invoiced) / Enquiries. Executive columns count all stages.
